Test Specification: Framework Testing

Scenario: Verify Framework Documentation
  Given I navigate to the Playwright documentation page
  When I click on different testing framework tabs
  Then I should see the corresponding code attributes displayed

Test Cases:
1. MSTest Framework
   - Navigate to documentation
   - Click MSTest tab
   - Verify "TestMethod" attribute is visible

2. NUnit Framework  
   - Navigate to documentation
   - Click NUnit tab
   - Verify "Test" attribute is visible

3. xUnit Framework
   - Navigate to documentation
   - Click xUnit tab
   - Verify "Fact" attribute is visible

Expected Results:
- All framework tabs should be clickable
- Code attributes should be clearly visible
- Navigation should work smoothly across different frameworks
